# 🎣 완전 입문자를 위한 순서

## 학습 로드맵

1. 개발을 할 수 있는 환경을 만들어 놓자
2. 뭐라도 만들어 보고 시작할까?
   - 아주 간단한 것 → **Step 1**
   - 하나의 화면을 그리기
   - 그렇지만 하나씩 천천히 → **Step 2**
3. 내가 만들었던 것들보다 더 발전된 것
   - 더 잘 그릴 수 있는 방법의 일부 → **Step 3**
4. 하나의 화면이 아니라 여러개의 화면을 그려보기
   - 네비게이션
   - 탭뷰 → **Step 4**
5. 여러 화면을 관통하는 데이터 전달
   - State, Binding → **Step 5**
6. 데이터를 저장해보자
   - 비지니스 로직 → **Step 6**
7. 그리고 그 다음에는?
   - 저장하기 → **Step 7**
