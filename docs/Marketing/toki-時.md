## 📱 기능 기획안

### 멀티 알림 타이머 (Multi-Alert Timer)

#### 1. 기능 목적

기존 타이머는 종료 시점에만 알림을 제공하는데 반해, **사용자가 원하는 시점에 사전 알림을 설정할 수 있도록** 하여 발표, 운동, 학습 등 시간 관리의 효율성을 높입니다.

#### 2. 사용 시나리오 예시

**예시: 30분 발표 타이머**
- 타이머 시작: 30분
- 알림 1: 15분 남았을 때 → "남은 시간 15분입니다."
- 알림 2: 5분 남았을 때 → "5분 전입니다. 마무리 준비하세요."
- 알림 3: 1분 남았을 때 → "곧 끝납니다. 마무리하세요."
- 타이머 종료 → "타이머 종료되었습니다."

#### 3. 핵심 기능 설계

| 기능 | 설명 |
|-----|-----|
| 타이머 설정 | 원하는 타이머 시간을 입력하거나 프리셋(10분, 15분, 30분 등)을 선택 |
| 사전 알림 설정 | 타이머 시간 기준으로 알림 시간을 여러 개 선택 가능 |
| 알림 미리보기 | 설정된 알림 시점을 타임라인 형태로 시각화 |
| 알림 메시지 커스터마이징 | 알림 문구 수정 가능 (기본 제공) |
| 알림 방법 설정 | 소리/진동/푸시 선택 가능 |
| 저장 기능 | 자주 사용하는 타이머/알림 조합을 템플릿으로 저장하여 재사용 가능 |

#### 4. UI/UX 설계 개요

**타이머 설정 화면 구성 (기본 버전)**

1. **타이머 시간 입력 영역** — 슬라이더 또는 숫자 입력
2. **알림 시점 추가 버튼** — "+ 알림 시점 추가" 클릭 → [시간선택: 몇 분 전]
3. **시각적 타임라인 미리보기** — 타이머 시작점부터 알림 시점까지 시각화
4. **시작 버튼** — 타이머 시작과 동시에 백그라운드에서 알림 예약

#### 5. 기능 확장

- 와치에서도 동일하게 사용가능
